## 모드 정의

| 모드 | 정의 | 전환 기준(예시) |
|---|---|---|
| 평시(Normal) | 일반 트래픽 운영 | 기본 모드 |
| 피크(Event) | 세일/드롭/프로모션 집중 트래픽 | RPS, 큐 랙, 재고 경합 지표 임계치 초과 |
| 비상(Emergency) | 장애 전파 억제 우선 모드 | Redis/Kafka/PG 장애 또는 SLO 급락 |

## 핵심 원칙

- 정합성 우선순위는 모드와 무관하게 동일하다. (DB 최종 권위, 멱등성 강제)
- 피크 모드는 성능 최적화를 추가하는 모드이지, 정합성 규칙 완화 모드가 아니다.
- 비상 모드는 기능 축소를 허용하되 주문/결제/재고 확정 경로를 최우선 보호한다.

## 전략 비교표

| 영역 | 평시(Normal) | 피크(Event) |
|---|---|---|
| CQRS | 커맨드/조회 분리 유지 | 조회모델 사전 워밍, 인기 상품 머티리얼라이즈드 뷰 강화 |
| DB 정합성 | 조건부 UPDATE + version + unique | 동일(절대 완화 금지) |
| 멱등성 키 | 결제/주문/취소 필수 | 동일 + TTL/스토리지 용량 사전 확장 |
| 락 전략 | 핫 SKU 중심 선택적 분산락 | 핫 SKU 락 적극 적용 + 락 경합 모니터링 강화 |
| 캐시 전략 | `Caffeine -> Redis -> DB` | 피크 대상 사전 가공 데이터 적재, 캐시 키 선배포 |
| 이벤트 처리 | 표준 컨슈머 병렬도 | 컨슈머/파티션 확장, DLQ 알림 민감도 상향 |
| 서버 확장 | 오토스케일 기본 정책 | 선제 스케일아웃(앱, Kafka consumer, Redis/DB read) |
| 실패 처리 | 표준 재시도/보상 | 빠른 폴백 + 비핵심 기능 킬스위치 즉시 적용 |
| 운영 통제 | 일반 알림 임계치 | 이벤트 전용 대시보드/온콜 워룸 운영 |

## 피크 모드 상세 정책

### 1) 사전 준비 (T-7 ~ T-1)

- 세일 대상 SKU/카테고리 조회 데이터를 Redis에 사전 가공 적재한다.
- 인기 상품 목록/가격/노출/재고 요약을 머티리얼라이즈드 뷰로 생성한다.
- 앱 서버, 컨슈머, DB 커넥션풀, Redis 노드 용량을 선제 증설한다.
- 멱등키 저장소 용량과 만료 배치를 점검한다.
- 락 경합/재고 경합 시나리오 부하 테스트를 수행한다.

### 2) 실시간 운영 (T0 ~ T+)

- 주문 커맨드 경로는 DB 정합성 검증을 유지한다.
- Redis 장애 시 즉시 DB-only 제한 모드로 전환한다.
- 비핵심 기능(추천, 리뷰 집계, 일부 정렬/필터)을 Feature Flag로 축소한다.
- Kafka 지연 시 Outbox 누적을 허용하고 주문 커맨드 성공 경로를 우선 보호한다.
- 즉시 발행 실패 이벤트는 10분 경과 배치 재발행으로 복구한다.

### 3) 사후 정리 (T+1 ~)

- 주문-결제-재고-정산 대사를 수행하고 불일치 건을 자동/수동 보정한다.
- 캐시 재적재 및 머티리얼라이즈드 뷰를 평시 정책으로 롤백한다.
- 이벤트 기간 SLO, 장애 지표, 재시도율을 회고하여 임계치를 갱신한다.

## 비상 모드(장애 전파 억제) 정책

| 대상 장애 | 즉시 조치 |
|---|---|
| Redis 네트워크/스로틀링 | 캐시 우회, DB-only 제한 모드, 읽기 기능 일부 축소 |
| Kafka 지연/장애 | Outbox 누적, 재발행 배치/컨슈머 재기동, 비핵심 비동기 기능 일시 중지 |
| PG 지연/오류 급증 | `PAYMENT_PENDING` 체류 비율 모니터링, 재조회 워커 증설 |
