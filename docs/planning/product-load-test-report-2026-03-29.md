## 해석

| 관찰 | 해석 |
|---|---|
| 200 rps 구간 p95 `3.02s -> 415.56ms` | N+1 제거 효과가 가장 크게 나타난 구간 |
| 200 rps dropped `202 -> 0` | 처리량 병목 완화로 안정성 개선 |
| 150 rps p99 `270.15ms -> 348.57ms` | tail latency 튀는 구간이 남아 있어 추가 점검 필요 |
| 램프 구간 p95 591ms | 급격한 부하 변동에도 임계치(1.2s) 이내 유지 |
